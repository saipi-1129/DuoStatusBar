# DuoStatusBar

macOSのメニューバーに、バッテリー残量とゲージ、ネットワーク、音量、CPUまたはメモリ情報をコンパクトに表示するSwiftUI/AppKitアプリです。ネットワークやバッテリーの状態はMac上で読み取ります。

## インストール

1. [Releases](../../releases)から、お使いのMac向けの`DuoStatusBar-<version>-<architecture>.dmg`をダウンロードします。
2. DMGを開き、`DuoStatusBar.app`を「アプリケーション」へドラッグします。
3. 初回起動時、未公証の開発ビルドについてmacOSが確認を表示した場合は、FinderでアプリをControlクリックして「開く」を選びます。

この配布物はDeveloper ID署名・Apple公証をしていないアドホック署名版です。macOSが開発元を確認できない旨を表示することがあります。ソースを確認してから起動してください。

## 必要環境

- macOS 14以降
- Apple Silicon向けDMGを配布します（別アーキテクチャ用はその環境でビルドしてください）
- Liquid Glass表示にはmacOS 26以降が必要です。それより前のmacOSではClassicテーマを利用できます。
- ソースからのビルドとDMG作成にはXcode 26以降、Swift 6、macOS Command Line Toolsが必要です。

## 機能

- バッテリー残量と連動するメニューバーゲージ。充電中は緑、低電力モード中は黄色で表示します。
- パネルに時刻、日付、バッテリー、ネットワーク、音量、出力先を表示します。
- CPU、使用済みメモリ（G単位）、音量の表示を選択できます。CPUとメモリは選択中の項目だけを計測します。
- メモリプレッシャー、低電力モード、ローカルIPv4アドレスを確認できます。
- 有線とWi-Fiのネットワークサービス優先順位を切り替えます。サービス自体は無効化しません。
- 音量の調整とオーディオ出力先の選択ができます。
- 充電中はバッテリー側の充電電力を概算して表示します。値は15秒ごとに更新され、充電器の定格やコンセント側の消費電力とは異なります。
- Classic / Liquid Glassを選択できます。選択と色などの設定はアプリ再起動後も保持されます。

## 操作と権限

メニューバーのインジケーターをクリックするとパネルが開きます。パレットボタンから外観とテーマ色を変更できます。バッテリー、ネットワーク、音量のカードから、それぞれの操作やmacOS設定へ移動できます。

ネットワークの優先順位変更と低電力モードの変更にはmacOSの管理者認証が必要になる場合があります。低電力モードは`pmset`で電源プロファイルを変更します。認証情報をアプリに保存したり、常駐の特権ヘルパーをインストールしたりしません。

アプリは分析データやテレメトリーを送信しません。設定はmacOSのユーザー設定に保存されます。

## ビルドと配布物作成

リポジトリのルートで実行します。

```sh
zsh scripts/build-app.sh
open build/DuoStatusBar.app
```

バージョンとCPUアーキテクチャを含むインストーラーDMGを作成し、アプリ署名、DMG、マウント後の内容を検証します。

```sh
zsh scripts/create-dmg.sh
```

成果物は`build/releases/`に作成され、SHA-256が出力されます。このフォルダーとビルド生成物はGit管理対象外です。DMGには`Applications`フォルダーへのリンクも入ります。

## プロジェクト構成

- `Sources/DuoStatusBar/`: SwiftUIのパネル、AppKitのメニューバー表示、システム情報とデバイス操作
- `Resources/Info.plist`: アプリの識別子、バージョン、最低対応OS
- `scripts/build-app.sh`: アプリバンドルの作成とアドホック署名
- `scripts/create-dmg.sh`: インストーラーDMGの作成と検証

## 配布上の注意

Releaseにはバージョン付きDMGとSHA-256チェックサムを添付します。現状は個人開発用のアドホック署名配布です。Developer ID署名や公証が必要な一般配布向けビルドとは異なります。
